# Smart Library IDEA Project

## Run in IntelliJ IDEA

1. Open this folder in IDEA:

   ```text
   C:\Users\31875\Documents\New project\SmartLibraryIDEA
   ```

2. Open `src/Main.java`.
3. Choose the run configuration `Run Smart Library`.
4. Click the green Run button.

If IDEA asks for a JDK, choose the installed Java 25 JDK.

## Run from Terminal

```powershell
javac -d out src\Main.java
java -cp out Main
```
